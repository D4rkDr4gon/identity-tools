Good to know

  • memberOf only lists direct membership. To include nested groups use the 1.2.840.113556.1.4.1941 rule (LDAP_MATCHING_RULE_IN_CHAIN), which is exact but can be expensive on large hierarchies.
  • In AD, computer inherits from user: (objectClass=user) also returns computers. For people, combine it with (objectCategory=person).
  • A leading wildcard (cn=*sales) cannot use the attribute index and forces a walk through every object in scope.
  • (!(attribute=value)) also returns objects that do not have that attribute. If that is not what you want, add (attribute=*).
